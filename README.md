# Playroom

A cheerful, responsive browser arcade with five original mini-games built using vanilla HTML, CSS, and JavaScript.

## Games

- Memory Match
- Snack Snake
- Tic-Tac-Toe
- Rock Paper Scissors
- Number Garden

## Run locally

Open `index.html` in a browser, or serve this folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

No build step or dependencies are required. The site uses Google Fonts when online and falls back to system sans-serif fonts if unavailable.
